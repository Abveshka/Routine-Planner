# Routine Planner

**Routine Planner** - веб-приложение для планирования сезонных целей и небольших шагов к ним. Цели можно распределять по году, сезону и периоду внутри сезона, добавлять к ним задачи и отмечать прогресс.

## Возможности

- Регистрация и вход в аккаунт.
- Создание, редактирование и удаление целей.
- Планирование целей по году, сезону и части сезона.
- Подзадачи с индивидуальной стоимостью.
- Отметка выполнения целей и подзадач.
- Календарный обзор целей.
- Подсчёт общей стоимости цели по подзадачам или вручную.

## Стек

- **Frontend:** React, TypeScript, Vite.
- **Backend:** ASP.NET Core 8, Entity Framework Core.
- **База данных:** PostgreSQL.
- **Авторизация:** JWT.
- **Запуск:** Docker Compose.

## Запуск через Docker

1. **Убедитесь, что Docker Desktop запущен.**

2. **Настройте переменные окружения.**

   В корне проекта, рядом с `docker-compose.yml`, создайте файл `.env` и добавьте в него следующие переменные:

   ```dotenv
   POSTGRES_PASSWORD=your-secure-database-password
   JWT_KEY=your-long-random-secret-key-at-least-32-characters
   ```

   Замените значения на собственные. `JWT_KEY` должен быть длинным случайным секретным ключом.

3. **Соберите и запустите приложение.**

   Выполните команду из корневой папки проекта:

   ```bash
   docker compose up --build
   ```

   При первом запуске Docker соберёт образы frontend и backend, запустит PostgreSQL и дождётся готовности базы данных перед запуском API.

4. **Откройте приложение в браузере.**

   - **Frontend:** http://localhost:5173
   - **API и Swagger UI:** http://localhost:5112/swagger

### Управление приложением

- Для запуска в фоновом режиме используйте:

  ```bash
  docker compose up --build -d
  ```

- Чтобы остановить приложение, нажмите `Ctrl+C`, если оно запущено в обычном режиме.

- Если приложение запущено в фоновом режиме, остановите его командой:

  ```bash
  docker compose down
  ```

Данные PostgreSQL сохраняются в Docker volume `pgdata` и остаются доступными после остановки и повторного запуска контейнеров.

## О проекте

**Routine Planner** - пет-проект для планирования целей и превращения больших планов в выполнимые шаги. Он объединяет клиентский интерфейс на React и TypeScript, REST API на ASP.NET Core и базу данных PostgreSQL. Docker Compose упрощает сборку и локальный запуск всех компонентов приложения.
